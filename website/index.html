Everything you need, nothing you don't

A focused writing and review tool for the docs you already keep in Markdown.

Anchored comments

Select text and comment on it. Threads support replies, edits and resolve/reopen, and flag themselves if the quoted text disappears.

Plain files

Every doc is a normal .md file. Open, edit, back up or version it with any tool. Outside changes show up live.

Instant search

Press ⌘K to search doc names and contents. Opening a result jumps to and highlights the first match.

Preview, split or source

A CodeMirror editor with find/replace, beside a live preview. Switch between Preview, Split and Markdown views.

Rich rendering

GitHub-flavored Markdown with tables and task lists, highlighted code, KaTeX math and Mermaid diagrams.

Safe autosave

Saves a second after you stop typing, atomically. If the file changed on disk, you're asked before anything is overwritten.

Links between docs

Relative links open the target doc at the right heading, and images load relative to the doc.

Table of contents

Built from your headings, with smooth scrolling and a highlight that follows where you are.

Export to PDF

Print just the rendered doc, with no app chrome, ready to share.

Your docs, your disk

No account, no cloud, no lock-in. Docs live in an ordinary folder, and name a doc team/standup to group it under "team" automatically.

  • Comments are stored in a local SQLite file next to your docs.
  • Files and folders starting with . stay hidden.
  • Paths are checked so nothing escapes the docs folder.
Docs/ ├── welcome.md ├── team/ │ ├── standup.md │ └── retro.md ├── guides/ │ └── setup.md └── .docs/ └── comments.db

macOS

macOS 14 or later · Apple Silicon and Intel

Download .dmg Universal Download .app.zip No disk image

The app isn't signed yet. On first launch, right-click it and choose Open, or run xattr -dr com.apple.quarantine "/Applications/Markdown Docs.app"

Linux

64-bit (x86_64)

Download .deb Ubuntu, Debian Download .AppImage Other distros

Install the .deb with sudo apt install ./Markdown-Docs_*_amd64.deb. For the AppImage, chmod +x it, then run it.
