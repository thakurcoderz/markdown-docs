§ 01

Everything you need, nothing you don't.

A focused writing and review tool for the docs you already keep in Markdown.

the big one

Anchored comments

Select text and comment on it. Threads support replies, edits and resolve/reopen, and flag themselves if the quoted text disappears.

Plain files

Every doc is a normal .md file. Open, edit, back up or version it with any tool. Outside changes show up live.

Instant search

Press ⌘K to search doc names and contents. Opening a result jumps to and highlights the first match.

Preview, split or source

A CodeMirror editor with find and replace, beside a live preview. Switch between Preview, Split and Markdown views.

Rich rendering

GitHub-flavored Markdown with tables and task lists, highlighted code, KaTeX math and Mermaid diagrams.

Paste or drop images

Paste a screenshot or drag image files into the editor. They're saved next to the doc and linked where your cursor is.

Drag to organize

Drag docs and folders around the sidebar, or rename them. Links and images in every doc are updated so nothing breaks.

Safe autosave

Saves a second after you stop typing, atomically. If the file changed on disk, you're asked before anything is overwritten.

Links between docs

Relative links open the target doc at the right heading, and images load relative to the doc.

Flexible layout

Hide or resize the sidebar and the contents/comments panel, or switch to Focus Mode to see only the doc.

Export to PDF

Print just the rendered doc, with no app chrome, ready to share.

Updates itself

New versions are checked, verified against a signature and installed for you. Turn it off anytime in Settings.

§ 02

Your docs, your disk.

No account, no cloud, no lock-in. Docs live in an ordinary folder, and naming a doc team/standup files it under "team" automatically.

  • Keep them in any folder, such as one Dropbox, Google Drive or Syncthing syncs between computers.
  • Comments are stored in a local SQLite file next to your docs.
  • Files and folders starting with . stay hidden.
  • Paths are checked so nothing escapes the docs folder.

§ 04

Take a copy home.

Free and open source. Pick your platform.

macOS

macOS 14 or later · Apple Silicon & Intel

Download .dmg Universal Download .app.zip No disk image

The app isn't signed yet. On first launch, right-click it and choose Open, or run: xattr -dr com.apple.quarantine "/Applications/Markdown Docs.app"

Linux

64-bit (x86_64)

Download .deb Ubuntu, Debian Download .AppImage Other distros

Install the .deb with: sudo apt install ./Markdown-Docs_*_amd64.debFor the AppImage, chmod +x it, then run it. After that, the app updates itself.
